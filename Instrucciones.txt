Analiza completamente el proyecto backend Proyect-BDNoSQL antes de escribir una sola línea de frontend.

OBJETIVO

Construir un frontend completo para demostrar todas las funcionalidades del proyecto de turismo basado en MongoDB Atlas, Vector Search, RAG, búsqueda multimodal y embeddings.

IMPORTANTE:

NO generar React.
NO generar Angular.
NO generar Vue.
NO generar Bootstrap.

Utilizar únicamente:

* HTML5
* CSS3
* JavaScript Vanilla (ES6+)

La intención es mantener el frontend simple, portable y fácil de explicar en una sustentación académica.

PRIMER PASO OBLIGATORIO

* app/main.py
* app/routes/*
* app/controllers/*
* app/services/*

* app/models/*
* app/repositories/*

Identificar:

1. Todos los endpoints disponibles.

3. Request Body.

Generar primero un mapa interno de APIs antes de construir el frontend.

NO asumir nombres de endpoints.

Leerlos del código.

─────────────────────────────────────

OBJETIVO DEL FRONTEND

El frontend debe permitir demostrar:

1. Consulta de destinos.
2. Consulta de paquetes turísticos.
3. Búsqueda vectorial texto → texto.
4. Búsqueda multimedia texto → imagen.
5. Búsqueda imagen → imagen usando CLIP.
6. Búsqueda multimodal.
7. Comparación de chunking.
8. Pruebas RAG.
9. Visualización de resultados.
10. Visualización de imágenes almacenadas en static/img.
